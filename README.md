# PK Farms

Farm-fresh online store for dairy, honey and farm produce. Next.js + TypeScript + Tailwind.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Structure

```
src/
├── app/          # Pages (home, shop, product, blogs, about, contact, account, policies)
├── components/
│   ├── common/   # Header, footer, product page and cart pieces
│   └── home/     # Home-page sections
└── lib/          # Product, blog, order and offer data
public/images/    # Site photos
```
